3. AESTHETIC DIRECTION AND MOODBOARD
================================================================================

Name of the aesthetic: LIQUID ARCHITECTURE.
Core idea:
  Solid architectural forms behaving like fluids. Translucent, refractive,
  subsurface-scattered materials. The feeling of watching resin cure in
  slow motion, or pigment suspended in oil.

Reference brief (send to 3D artist or use for mental model):
  - Material: frosted translucent resin with an inner glow. Think Iris van
    Herpen's 3D-printed dresses + James Turrell's Skyspaces + Yuri Suzuki's
    instrument sculptures.
  - Light: a single directional key at 45 degrees, color temperature 5600K,
    plus a slow-rotating iris-violet rim light. HDRI is subtle, desaturated
    studio.
  - Camera: always 35mm equivalent, shallow depth of field in acts 3 and 5,
    wide and deep in act 2.
  - Post: gentle bloom on the iris accent only. No film grain. No LUT
    shift. The image must feel digital-pure, not filmic.
  - Never use: chrome, holographic, iridescent rainbow gradients, Y2K,
    fluffy 3D blobs, vaporwave. These are oversaturated. We are going
    cooler, more sculptural, more editorial.

Reference sites (for Cursor to browse if it wants inspiration only; do not
copy):
  - igloo.inc                    (scroll choreography rigor)
  - oliviersarfati.com           (single-object hero)
  - studio-lumio.com             (editorial type + 3D)
  - humanoid.to                  (material quality)
  - dogstudio.com/story/exodus   (scroll narrative structure)

Do not clone any of the above. Pull the discipline, leave the surface.

================================================================================
11. THE SEED — MODELLING SPEC (BLENDER)
================================================================================

Deliverable: one file, `public/models/seed.glb`. Draco-compressed. Under
500KB.

Contents:
  - One mesh named "seed"
  - 15,000 triangles maximum, evenly distributed
  - UV-unwrapped, non-overlapping
  - Five shape keys (morph targets), all normalized to Basis = spark:

Shape key 1 — spark
  Tiny icosphere, radius 0.2 units. Surface very slightly displaced by low-
  frequency noise. Reads as a single point from 3 meters away.

Shape key 2 — bloom
  12 petal-like shells radiating outward from center. Each petal is a
  lofted curve, slightly twisted. Overall silhouette ~4 units wide, 3 tall.
  Petals pierce each other intentionally at center.

Shape key 3 — fusion
  Stepped crystalline form. Vertical emphasis. 5 stacked faceted tiers,
  each rotated 22 degrees from the one below. Total height 5 units, width
  1.8. Feels architectural, almost a tower.

Shape key 4 — current
  Elongated ribbon. Moebius-like 1.5 twist. Length 7 units, width 1.
  Thickness 0.15. Smooth, flowing.

Shape key 5 — pool
  Flat disc, radius 4, thickness 0.1. Top surface displaced by very low
  amplitude concentric ripples. Reads mirror-like when lit from above.

Export settings:
  Format:        GLB 2.0
  Compression:   Draco, level 7
  Include:       normals, UVs, morph targets
  Exclude:       animations, cameras, lights
  Apply:         all transforms
  Scale:         1.0

If you cannot create this asset, proceed with the procedural fallback in
Section 12 — it is a viable v1 ship path.

================================================================================
12. THE SEED — PROCEDURAL FALLBACK SPEC
================================================================================

If no GLB is available, use a high-subdivision IcosahedronGeometry driven
entirely by the custom shader. The shader carries all five acts via a
single `uProgress` uniform (0 to 1) and a derived `uAct` (0 to 4).

Geometry:
  new THREE.IcosahedronGeometry(1, 64)    // ~40k tris, plenty of verts

All transformation is done in the vertex shader via layered simplex noise
whose frequency, amplitude, and directional bias change across acts. See
Section 13 for the full shader.

This path ships faster and is perfectly capable of award-tier quality.
Upgrade to GLB morph targets only when the procedural version is dialed.

13. SHADER CODE (FULL GLSL)

--- shaders/includes/noise.glsl ---
// Classic Perlin 3D noise by Stefan Gustavson, public domain.
// Source reference: github.com/stegu/webgl-noise
// (Cursor: include the standard cnoise / snoise function here. The
// canonical implementation is ~80 lines. Copy verbatim from
// github.com/stegu/webgl-noise/blob/master/src/classicnoise3D.glsl )

float snoise(vec3 v);
float fbm(vec3 p) {
  float v = 0.0;
  float a = 0.5;
  for (int i = 0; i < 5; i++) {
    v += a * snoise(p);
    p *= 2.0;
    a *= 0.5;
  }
  return v;
}

--- shaders/includes/fresnel.glsl ---
float fresnel(vec3 N, vec3 V, float power) {
  return pow(clamp(1.0 - dot(normalize(N), normalize(V)), 0.0, 1.0), power);
}

--- shaders/includes/easing.glsl ---
float easeInOutCubic(float t) {
  return t < 0.5 ? 4.0 * t * t * t : 1.0 - pow(-2.0 * t + 2.0, 3.0) / 2.0;
}
float smoothActMix(float progress, float center, float radius) {
  return 1.0 - smoothstep(0.0, radius, abs(progress - center));
}

--- shaders/seed.vert.glsl ---
#pragma glslify: snoise = require(./includes/noise.glsl)
#pragma glslify: fbm    = require(./includes/noise.glsl)
#pragma glslify: smoothActMix = require(./includes/easing.glsl)

uniform float uTime;
uniform float uProgress;   // 0..1 overall
uniform float uAct;        // 0..4
uniform vec2  uMouse;      // -1..1

varying vec3 vNormal;
varying vec3 vWorldPos;
varying vec3 vViewDir;
varying float vDisplacement;
varying float vAct;

void main() {
  vec3 pos = position;
  vec3 nrm = normal;

  // Base slow breath
  float breath = sin(uTime * 0.6) * 0.03;

  // Mouse pull — world-space attraction toward cursor
  vec3 mousePull = vec3(uMouse.x, uMouse.y, 0.0) * 0.15;

  // Per-act noise regimes
  float wSpark   = smoothActMix(uAct, 0.0, 1.0);
  float wBloom   = smoothActMix(uAct, 1.0, 1.0);
  float wFusion  = smoothActMix(uAct, 2.0, 1.0);
  float wCurrent = smoothActMix(uAct, 3.0, 1.0);
  float wPool    = smoothActMix(uAct, 4.0, 1.0);

  float nSpark   = fbm(pos * 3.0 + uTime * 0.2) * 0.05;
  float nBloom   = fbm(pos * 1.2 + uTime * 0.1) * 0.9;
  float nFusion  = abs(snoise(pos * 4.0 + vec3(0.0, uTime * 0.05, 0.0)))
                   * 0.35;
  float nCurrent = snoise(pos * vec3(0.5, 8.0, 0.5) + uTime * 0.3) * 0.55;
  float nPool    = sin(length(pos.xz) * 6.0 - uTime * 1.2) * 0.04;

  float displacement =
      nSpark   * wSpark
    + nBloom   * wBloom
    + nFusion  * wFusion
    + nCurrent * wCurrent
    + nPool    * wPool
    + breath;

  // Act-specific silhouette warps
  // Fusion: vertical stretch + rotational shear per height tier
  float fusionStretch = mix(1.0, 1.6, wFusion);
  pos.y *= fusionStretch;

  // Current: longitudinal stretch
  float currentStretch = mix(1.0, 2.4, wCurrent);
  pos.x *= currentStretch;

  // Pool: flatten
  float poolFlatten = mix(1.0, 0.08, wPool);
  pos.y *= poolFlatten;

  pos += nrm * displacement;
  pos += mousePull * (0.4 + wBloom * 0.6);

  vec4 worldPos = modelMatrix * vec4(pos, 1.0);
  vWorldPos = worldPos.xyz;
  vNormal = normalize(normalMatrix * nrm);
  vViewDir = normalize(cameraPosition - worldPos.xyz);
  vDisplacement = displacement;
  vAct = uAct;

  gl_Position = projectionMatrix * viewMatrix * worldPos;
}

--- shaders/seed.frag.glsl ---
#pragma glslify: fresnel = require(./includes/fresnel.glsl)

uniform float uTime;
uniform float uProgress;
uniform float uAct;
uniform vec3  uColorA;   // obsidian
uniform vec3  uColorB;   // iris
uniform vec3  uColorC;   // bone
uniform sampler2D uCaustics;

varying vec3 vNormal;
varying vec3 vWorldPos;
varying vec3 vViewDir;
varying float vDisplacement;
varying float vAct;

void main() {
  // Fresnel rim — stronger in acts 2 and 4
  float rim = fresnel(vNormal, vViewDir, 2.6);

  // Fake subsurface via displacement-modulated tint
  float interior = smoothstep(-0.2, 0.6, vDisplacement);
  vec3 sss = mix(uColorA, uColorB, interior);

  // Caustics scrolling
  vec2 uvC = vWorldPos.xz * 0.2 + uTime * 0.03;
  float caustics = texture2D(uCaustics, uvC).r * 0.25;

  // Base color = obsidian with iris rim and caustic highlights
  vec3 color = uColorA;
  color = mix(color, sss, 0.55);
  color = mix(color, uColorB, rim * 0.9);
  color += caustics * rim;

  // Act-specific tweaks
  // Pool (act 4): bright top-down highlight
  float poolWeight = smoothstep(3.2, 4.0, vAct);
  color = mix(color, uColorC, poolWeight * pow(max(vNormal.y, 0.0), 2.0));

  // Final alpha — translucent, thicker areas more opaque
  float alpha = clamp(0.55 + rim * 0.5, 0.4, 0.95);

  gl_FragColor = vec4(color, alpha);
}

15. CAMERA RIG AND SPLINE
================================================================================

The camera follows a Catmull-Rom spline with 5 control points, one per
act. Scroll progress samples the curve.

components/scene/CameraRig.tsx (essence):

  import { useFrame, useThree } from "@react-three/fiber";
  import * as THREE from "three";
  import { useMemo } from "react";
  import { useScroll } from "@/lib/scroll";

  const points = [
    new THREE.Vector3( 0.0,  0.0, 5.0),   // Act 1 Spark
    new THREE.Vector3( 3.0,  1.0, 7.0),   // Act 2 Bloom
    new THREE.Vector3( 0.5,  0.5, 4.5),   // Act 3 Fusion
    new THREE.Vector3(-2.0, -1.0, 6.5),   // Act 4 Current
    new THREE.Vector3( 0.0,  3.0, 8.5),   // Act 5 Pool
  ];

  const lookPoints = [
    new THREE.Vector3(0, 0, 0),
    new THREE.Vector3(0, 0, 0),
    new THREE.Vector3(0, 0.5, 0),
    new THREE.Vector3(0, 0, 0),
    new THREE.Vector3(0, 0, 0),
  ];

  export default function CameraRig() {
    const { camera } = useThree();
    const curve = useMemo(
      () => new THREE.CatmullRomCurve3(points, false, "catmullrom", 0.4),
      []
    );
    const lookCurve = useMemo(
      () => new THREE.CatmullRomCurve3(lookPoints, false, "catmullrom", 0.4),
      []
    );
    const target = useMemo(() => new THREE.Vector3(), []);
    const look = useMemo(() => new THREE.Vector3(), []);

    useFrame(() => {
      const p = useScroll.getState().progress;
      curve.getPointAt(p, target);
      lookCurve.getPointAt(p, look);
      camera.position.lerp(target, 0.08);
      camera.lookAt(look);
    });

    return null;
  }

Use leva (dev-only) to fine-tune the five keypoints interactively, then
hardcode them.

16. SCROLL SYSTEM (LENIS + ZUSTAND)
================================================================================

lib/scroll.ts:

  import { create } from "zustand";
  interface ScrollState {
    progress: number;
    act: number;
    set: (p: number) => void;
  }
  export const useScroll = create<ScrollState>((set) => ({
    progress: 0,
    act: 0,
    set: (progress) =>
      set({ progress, act: Math.min(4, Math.floor(progress * 5)) }),
  }));

components/providers/LenisProvider.tsx:

  "use client";
  import Lenis from "lenis";
  import { useEffect } from "react";
  import { useScroll } from "@/lib/scroll";
  import gsap from "gsap";
  import { ScrollTrigger } from "gsap/ScrollTrigger";

  gsap.registerPlugin(ScrollTrigger);

  export default function LenisProvider({
    children,
  }: { children: React.ReactNode }) {
    useEffect(() => {
      const lenis = new Lenis({
        duration: 1.2,
        easing: (t) => Math.min(1, 1.001 - Math.pow(2, -10 * t)),
        smoothWheel: true,
      });
      const raf = (time: number) => {
        lenis.raf(time);
        requestAnimationFrame(raf);
      };
      requestAnimationFrame(raf);

      lenis.on("scroll", ({ scroll, limit }: any) => {
        const p = limit ? scroll / limit : 0;
        useScroll.getState().set(p);
        ScrollTrigger.update();
      });

      return () => lenis.destroy();
    }, []);
    return <>{children}</>;
  }

20. CUSTOM CURSOR
================================================================================

components/ui/Cursor.tsx (essence):

  "use client";
  import { useEffect, useRef } from "react";

  export default function Cursor() {
    const ref = useRef<HTMLDivElement>(null);
    useEffect(() => {
      const el = ref.current!;
      let x = 0, y = 0, tx = 0, ty = 0;
      const move = (e: MouseEvent) => { tx = e.clientX; ty = e.clientY; };
      window.addEventListener("mousemove", move);
      const raf = () => {
        x += (tx - x) * 0.18;
        y += (ty - y) * 0.18;
        el.style.transform = `translate(${x}px, ${y}px)`;
        requestAnimationFrame(raf);
      };
      raf();
      return () => window.removeEventListener("mousemove", move);
    }, []);
    return (
      <div
        ref={ref}
        aria-hidden
        className="pointer-events-none fixed left-0 top-0 z-[80]
                   -translate-x-1/2 -translate-y-1/2 w-2 h-2 rounded-full
                   bg-bone mix-blend-difference transition-transform"
      />
    );
  }

Hover rule: any element with data-cursor="hover" scales the cursor to
32px with a soft iris ring. Implement via a CSS target rule.

Touch devices: hide cursor entirely via `@media (hover: none)`.

Mouse position is also pushed to the shader via useMousePosition hook.

  - Draco compression on GLB
  - 1k HDRI, compressed .hdr, or swap for RoomEnvironment preset
  - dpr cap at 1.5
  - antialias false + FXAA in post (cheaper than MSAA)
  - frameloop="always" but let useScroll + useFrame drive updates; if
    measuring reveals redundant renders, switch to "demand" and invalidate
    on scroll
  - Throttle shader uniform updates to 60Hz max
  - Use <PerformanceMonitor> from drei to degrade dpr on low frame rates
  - Preload critical font files with next/font
  - Lazy-mount PostFX after initial paint
  - Use CSS contain: layout paint for overlays
  - No layout shift: reserve image dimensions, fonts via next/font
  - No third-party scripts on first paint; analytics loaded after idle

Memory:
  - Dispose geometry and materials on unmount (canvas stays mounted though
    in our case)
  - Cap texture sizes at 1024 where possible
  - Use mipmaps for caustics texture

Network:
  - Self-host all fonts and HDRI
  - Immutable caching on /public via Vercel defaults
  - Avoid any runtime data fetching on home

26. REDUCED-MOTION FALLBACK
================================================================================

When prefers-reduced-motion: reduce:
  - Lenis smoothing OFF (native scroll).
  - Shader disables vertex noise (set uTime multiplier to 0 via uniform).
  - Camera stops moving; stays at average position of the five keypoints.
  - Copy cross-fades rather than word-by-word reveals.
  - Post-processing bloom fixed at medium, no scroll ramp.
  - Custom cursor hidden; default OS cursor shown.
  - Ripples on pool replaced with a static subtle glow.

Key: the reduced-motion version still tells the same story. Each act is
still a distinct visual moment, just without the animation connective
tissue. This is a must for inclusive design and for awards juries.

Implementation:
  lib/usePrefersReducedMotion.ts returns a boolean. Scene and Lenis read
  it and branch accordingly.
